# WorldChef3D

Mobile-first 3D restaurant management game prototype.

## MVP
- Real-time 3D restaurant scene
- Timed customer orders
- Cooking station with upgrades
- Cash, XP, reputation and inventory
- Recipe progression
- Special contracts
- Millionaire VIP orders paying 2x
- Alien event
- World map progression
- Portrait/mobile-first UI

The progression is intentionally objective-based: one burger never jumps the player through multiple levels.

## Run
Open index.html in a modern browser. Three.js is loaded from a CDN.

## Roadmap
Character animation, more recipes/stations, persistent saves, employees, restaurant expansion, more cities, and native Android/iOS packaging.
